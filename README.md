# arseneferret

Personal website for Arsene Ferret - Full Stack Developer

## About

This is a clean and modern personal website showcasing skills, projects, and contact information.

## Features

- Responsive design that works on all devices
- Clean and professional layout
- Sections for About, Skills, Projects, and Contact
- Modern CSS with smooth animations and transitions
- Easy to customize and maintain

## Usage

Simply open `index.html` in a web browser to view the website.

## Sections

- **Hero**: Welcome section with a call-to-action
- **About**: Personal introduction and background
- **Skills**: Technical skills organized by category
- **Projects**: Portfolio of completed projects
- **Contact**: Ways to get in touch

## Customization

To customize the website for your own use:

1. Edit `index.html` to update content (name, bio, skills, projects, contact info)
2. Modify `styles.css` to change colors, fonts, and layout
3. Update the color scheme by changing CSS variables in `:root`

## Deployment

This website can be deployed to any static hosting service such as:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Or any web server
